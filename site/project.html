SoC / RISC-V / FPGA

YScore

YScore = Your Simple Core —— 从 0 手写的 RV32 SoC：用 Verilog 实现的 5 级多周期 RISC-V 处理器（RV32I + Zicsr），支持 ecall/ebreak 内部异常与 CLINT 定时器中断； 自研 AXI4-Lite 主控与 UART/GPIO/CLINT 外设；18KB 指令存储 + 24KB 数据存储； 并在其上运行裸机抢占式时间片轮转 RTOS（含 Shell 命令行与 Asteroids 小游戏）。 先在 QEMU 上验证，再移植到 Altera Cyclone IV E FPGA。

YScore = Your Simple Core — an RV32 SoC written from scratch: a hand-written Verilog 5-stage multi-cycle RISC-V processor (RV32I + Zicsr) with ecall/ebreak exceptions and CLINT timer interrupts, a custom AXI4-Lite master, UART/GPIO/CLINT peripherals, 18KB instruction + 24KB data memory, and a bare-metal preemptive round-robin RTOS with a shell and an Asteroids mini-game. Verified on QEMU first, then ported to an Altera Cyclone IV E FPGA.

  • Verilog
  • RISC-V
  • AXI4-Lite
  • RTOS
  • Quartus

EDA / Routing / C++17

FPGA-Router-Experiment

FPGA 协商布线器 —— 从零实现的 C++17 FPGA 布线引擎：以 Kruskal 最小生成树拆分多端线网， 用 BFS / A* / Mikami-Tabuchi 完成详细布线，并通过基于 OpenMP 的并行 PathFinder 协商布线化解拥塞；附带布线过程的交互式可视化（占用热力图与拥塞图）。

FPGA Negotiated Router — a from-scratch C++17 FPGA routing engine. It decomposes multi-terminal nets with a Kruskal MST, routes them with BFS / A* / Mikami-Tabuchi detail routing, and removes congestion with a parallel PathFinder negotiated router driven by OpenMP. Includes an interactive visualization of the routing process (occupancy heatmap and congestion map).

  • C++17
  • PathFinder
  • BFS / A*
  • OpenMP
  • Visualization
